# experience-ui

The web client a farmer uses to ask the OpenAgriNet assistant a question and read its answer.

## Language

**Answer**:
The assistant's finished reply to one question, shown once it has fully arrived.
_Avoid_: Response, reply, message

**Source**:
Something an Answer drew on, such as a publication or an agency, known by its name. An Answer can have none or several.
_Avoid_: Reference, credit, origin

**Citation**:
A stretch of an Answer's text that points at one Source.
_Avoid_: Footnote, annotation
